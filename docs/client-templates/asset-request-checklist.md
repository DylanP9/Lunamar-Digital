# Asset Request Checklist — Lunamar Digital

> Draft template. Send to the client to collect everything needed to build and launch.

## Brand
- [ ] Logo files (SVG / PNG / high-res)
- [ ] Brand guidelines (if any)
- [ ] Brand colours and fonts (if known)

## Imagery
- [ ] Photos (general)
- [ ] Product / service photos
- [ ] Team photos (if needed)
- [ ] Videos / clips (for reels, if on Grow/Partner)

## Business information
- [ ] Menu / service list
- [ ] Pricing
- [ ] Opening hours
- [ ] Contact details (phone, email, address)
- [ ] Google Business Profile link
- [ ] Google reviews link
- [ ] Social links

## Technical access
- [ ] Domain login or DNS access
- [ ] Existing hosting access (if any)
- [ ] Existing analytics / Search Console access (if any)

## Legal / copy
- [ ] Any existing privacy policy / legal text
- [ ] Any required disclaimers or compliance text

---

*Tip: shoots and photography days are quoted separately — confirm whether the client is supplying their own imagery before build starts.*
